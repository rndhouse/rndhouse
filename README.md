I build small, inspectable tools for the parts of software work that are getting weird: agents that need semantic control over code, package ecosystems that need better review, and open-source projects that need better incentives.

Follow along if you are interested in:

- Rust tools with a bias toward practical systems work.
- AI coding agents, local-model workflows, and token-efficient orchestration.
- Package review, dependency risk, and software supply-chain infrastructure.
- Funding mechanisms for open-source software.
- Security research prototypes that turn quiet signals into useful warnings.

## Thread

The common thread is developer infrastructure for a post-agent world:

- Code needs to be easier for tools to inspect, modify, and verify.
- Package ecosystems need review systems that scale beyond trust and vibes.
- Open-source funding needs mechanisms closer to usage than sponsorship theater.
