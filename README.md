# rndhouse

Building Rust systems for software supply-chain review, AI-assisted development, and security-adjacent tooling.

## Current Focus

- [thirdpass](https://github.com/thirdpass-org/thirdpass): multi-ecosystem package code review for software supply chains.
- [mixmod](https://github.com/rndhouse/mixmod): reducing frontier-model token usage by supervising smaller local models.

## Related Work

[draxl](https://github.com/draxl-org/draxl) explores agent-native source annotations. [vcamper](https://github.com/rndhouse/vcamper) is a proof of concept for spotting silent security patches before CVEs.

Past projects: [openfare](https://github.com/openfare/openfare), [sdsl-rs](https://github.com/sdsl-rs/sdsl-rs).
